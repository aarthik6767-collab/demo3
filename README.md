# MindMate — Mental Wellness Support Chatbot

A polished Flask-based mental wellness support chatbot designed for a college project/demo.

## Features

- Modern responsive chat interface
- Mood quick-actions
- Typing indicator
- Chat timestamps
- Clear chat button
- Local browser chat history
- Rule-based mental wellness responses
- Crisis keyword detection with emergency guidance
- No API key required
- Easy to run on Windows

## Run

Open PowerShell/Terminal in this folder:

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Install:

```bash
python -m pip install -r requirements.txt
```

Start:

```bash
python app.py
```

Open:

http://127.0.0.1:5000

## Important

MindMate is a supportive educational chatbot, not a doctor, therapist, or emergency service. It should not diagnose mental-health conditions or replace professional care.
